# GenAI Storytelling Engine

An advanced prompt-driven generative AI engine built using Large Language Models (LLMs) with optimized context tuning and parameter controls for creative and logical text generation.

## 🚀 Features
* **Prompt Optimization:** System prompts structured to enforce narrative coherence and thematic consistency.
* **Parameter Tuning:** Controlled text generation using custom `temperature` and `top_p` constraints.
* **Structured Output:** Parses and formats raw model output into clean, readable narrative chapters.

## 🛠️ Tech Stack
* Python
* Google GenAI / OpenAI APIs
* LangChain concepts
